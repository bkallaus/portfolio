**PR Title:** feat: Word Counter tool

**The Problem Solved:** Provides a quick, real-time calculation of word, character, sentence, and paragraph counts for text inputted by the user, enhancing the utility of the application's developer tools suite.

**Visuals:** [Screenshot](/home/jules/verification/screenshots/verification.png)

**Implementation Journey:**
- Investigated the current tools (e.g. `PasswordGenerator`, `LoremIpsum`).
- Evaluated options for a net-new tool and decided on a `WordCounter`.
- Created `WordCounter` component using Shadcn UI components.
- Integrated the component into `App.tsx` and added navigation in `side-nav.tsx`.
- Refactored project testing to use `vitest` with `jsdom` since `jest` was failing to resolve paths and standard npm test script was missing.
- Implemented robust unit tests for the word counter statistics and UI interactions.
- Verified functionality with Playwright end-to-end tests and visual screenshot review.

**Tradeoffs & Assumptions:**
- I assumed the user wanted a new feature that matches the spirit of the existing utility tools.
- I considered 3 options: HTML Entity Encoder, Regex Tester, and Word Counter. I chose Word Counter for its broad utility and simplicity.
- The project used `npm test` but lacked a configured test runner, so I assumed switching to Vite-native `vitest` was the appropriate architectural choice to unblock development safely.

**Testing Instructions:**
1. Check out the branch: `git checkout feature/word-counter`
2. Start the dev server: `npm start`
3. Navigate to `#word-counter` via the side nav.
4. Paste text into the textarea and verify the stats update in real-time.
5. Run unit tests locally: `npm run test`
