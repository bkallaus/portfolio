# No Comments Rule

This codebase has a strict rule against writing comments in the code. Code should be self-documenting.

When instructed to write or modify code, you must not include any inline comments, block comments, or documentation comments (unless explicitly required by a tool, which is rare).

Instead of writing a comment:
- Extract logic into well-named functions or methods.
- Use descriptive and clear variable names.
- Ensure the code's structure naturally conveys its intent.
